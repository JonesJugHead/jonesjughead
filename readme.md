### Hey, I'm me

Web dev by day, tinkerer by night. I mostly build small tools that scratch my own itch: dev utilities, browser extensions, and a lot of Minecraft stuff.

**Daily stack:** React · TypeScript · Vite · Tailwind · PHP
**Also:** Go · Node.js · Python · Java (Fabric / Paper)

---

#### Projects

| | |
|---|---|
| [**sleepy**](https://github.com/JonesJugHead/sleepy) | Sleep/wake wrapper for Minecraft servers on Pterodactyl. Java stays off while nobody plays (~4 MB RAM idle). `Go` |
| [**githeat**](https://github.com/JonesJugHead/githeat) | VS Code extension: git history heatmap of files, folders, blocks and lines. `TypeScript` |
| [**claude-sessions**](https://github.com/JonesJugHead/claude-sessions) | Local web UI to browse, search, rename and resume Claude Code sessions. `JavaScript` |
| [**git-timesheet**](https://github.com/JonesJugHead/git-timesheet) | Turns local git activity into a day-by-day timesheet per project, as a single HTML page. `HTML` |
| [**tupo-replay**](https://github.com/JonesJugHead/tupo-replay) | Firefox extension for playtupo.com: records your games and exports them as animated GIFs. `TypeScript` |
| [**devcopy**](https://github.com/JonesJugHead/devcopy) | Fabric client mod: copy scoreboard, tab, boss bars, titles and action bar text, record particle packets. `Java` |
